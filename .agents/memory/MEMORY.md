- [Deployment build Metro timeout](deployment-build-timeout.md) — production publish fails because Metro iOS/Android compilation exceeds 2-min timeout; fix is to pre-build with production domain and commit static-build.
- [Silent token refresh architecture](silent-token-refresh.md) — external backend has no /auth/refresh endpoint; solved with server-side encrypted credential cache in auth_sessions PostgreSQL table.
- [DB schema migration interactive prompts](db-migration-interactive.md) — drizzle-kit push blocks on interactive prompts for new tables; bypass by running raw SQL via node pg Pool directly.
- [Typography constants usage](typography-constants.md) — Typography object only has style-object keys (h1, h2, small, label, caption, body, etc.), NOT numeric shortcuts like .sm/.xs/.base/.lg. Use inline numbers or Typography.small.fontSize for fontSize in StyleSheet.
- [Team System architecture](team-system-arch.md) — departments/shifts/handovers live in local PostgreSQL; cases remain on external backend. Merge on caseId (text) client-side. Route files in server/routes/*.ts, registered via registerXxxRoutes() calls at end of registerRoutes() in routes.ts.
- [Razorpay integration approach](razorpay-integration.md) — uses Payment Links API (no native SDK, no npm package) via fetch + Basic auth. Webhook needs RAZORPAY_WEBHOOK_SECRET env var to verify signatures.
- [Cases proxy dual-UUID problem](cases-proxy-dual-uuid.md) — external backend uses different UUID for JWT sub vs case created_by_user_id; fix is to return all cases when 0 matched but all cases share one unique owner UUID (backend pre-filtered by auth).
- [Healthcheck route ordering](healthcheck-route-order.md) — health-probe intercept for GET "/" must be registered BEFORE configureExpoAndLanding(); otherwise Expo's "/" handler wins and returns 500 to Replit's deployment healthcheck, killing the process.
- [Token refresh Render cold-start](token-refresh-render-coldstart.md) — proactive refresh buffer must be 30 min (not 5 min) so Render's 50 s cold-start has time to resolve; silent refresh needs 3 retries with 2 s/4 s backoff.
- [Department shift system bugs](dept-shift-bugs.md) — two structural bugs fixed: (1) route ordering: invites/pending must be registered BEFORE /:id/pending or Express matches "invites" as :id → NaN in DB query → 500; (2) userId mismatch: join stores Google sub, app JWT has external backend UUID — fixed by email-based fallback + self-healing in GET /api/department/my using auth_sessions.email.
- [Tab screens must not use useHeaderHeight](tab-header-height.md) — MainTabNavigator has headerShown:false for all tabs; calling useHeaderHeight() inside any tab screen throws "no header context" in React Nav 7, crashing the entire app via ErrorBoundary. Use useSafeAreaInsets().top instead.
- [Post-merge script location](post-merge-script.md) — post-merge hook wasn't configured; script must live outside scripts/ (forbidden dir) — placed at tools/post-merge.sh, runs npm install + clears static-build so merged client changes rebuild.
- [Unimported helper crashes whole server](unimported-helper-crash-server.md) — a route referencing a helper (e.g. extractUserId) without importing it doesn't fail at build time under tsx; it throws an uncaught ReferenceError at request time that kills the entire Node process, not just that request.
