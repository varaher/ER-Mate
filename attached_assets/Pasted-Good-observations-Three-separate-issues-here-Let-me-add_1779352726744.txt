## Issue 3 — Triage Blocking New Patient Flow

This is your most important observation and you're absolutely correct.

**The current problem:**
```
Doctor taps New Patient
         ↓
Triage screen opens
         ↓
Expects vitals, symptoms, 
triage category
         ↓
Doctor hasn't seen the patient 
properly yet
         ↓
Skips triage or enters wrong data
         ↓
Only then reaches case sheet
         ↓
Voice recording starts here
         ↓
But patient name/age already 
entered in triage — 
now entered twice
```

**What actually happens in a Kerala ER:**

```
Patient walks in or arrives by ambulance
         ↓
Doctor glances at patient
         ↓
Opens ErMate
         ↓
Wants to immediately start 
recording the consultation
         ↓
Triage is a barrier, not a help
```

**The right flow:**

```
Doctor taps + (new case)
         ↓
Two clear options ONLY:

┌─────────────────────────────────┐
│  🎙 Speak This Case             │
│  Talk naturally — ErMate fills  │
│  everything including triage    │
│                                 │  
│  ✏️  Fill Manually              │
│  Triage → Case Sheet step by   │
│  step                           │
└─────────────────────────────────┘
```

**Voice path — no triage screen at all:**
```
Doctor taps "Speak This Case"
         ↓
Microphone opens immediately
         ↓
Doctor speaks naturally — 
patient name, age, complaint, 
vitals, history, everything
         ↓
ErMate extracts triage category 
automatically from the vitals 
mentioned in the dictation
         ↓
Case sheet opens pre-filled
         ↓
Triage data already populated 
from what was spoken
```

**Manual path — triage first:**
```
Doctor taps "Fill Manually"
         ↓
Quick patient details screen
(name, age, sex only — 
not full triage form)
         ↓
Then case sheet opens
         ↓
Doctor fills as needed
```

**Triage category should be auto-assigned** from vitals in the voice dictation — not a separate screen the doctor has to fill before they've even properly assessed the patient.
