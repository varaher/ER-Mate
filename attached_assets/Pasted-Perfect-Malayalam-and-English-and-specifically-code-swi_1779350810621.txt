## Why This Combination Is Actually Ideal for Testing

Kerala ER doctors speak in a very specific pattern:

```
"Patient വന്നത് sudden onset 
 facial weakness with, 
 yesterday evening മുതൽ...
 BP കൂടുതലാണ്, known diabetic,
 VBG എടുക്കണം, 
 Neurology inform ചെയ്തു"
```

Malayalam grammar + English medical terms mid-sentence. Sarvam handles this natively because it was trained on Indian language code-switching, not just pure Malayalam.

## Before the Device Test — One Specific Check

Tell your developer to verify Sarvam is configured for Malayalam:

```javascript
// In your Sarvam transcription call
// Verify language_code is 'unknown' 
// not hardcoded to 'en-IN'

formData.append('language_code', 'unknown'); 
// 'unknown' = auto-detect
// This is critical for Malayalam detection

// If it's hardcoded to 'en-IN' 
// Malayalam will be forced through 
// English STT and produce garbage
```

If `language_code` is set to `'unknown'`, Sarvam auto-detects Malayalam and uses the correct model. If it's hardcoded to English, the transcription will fail on Malayalam words.

## If Any Field Fails

| Problem | Likely Cause | Fix |
|---|---|---|
| Malayalam words appear in HPI verbatim | Translation step failing | Check `/api/voice/translate` is being called |
| Past medical as single string | Old bug resurfaced | Verify array split in buildClinical |
| Doctor names missing | Extraction prompt issue | Check emResident/emConsultant fields in prompt |
| ECG finding not captured | Not in extraction schema | Add ecg findings to investigations block |
| Medications not split | Parsing issue | Check medication array in master schema |

## After Device Test Passes

You're ready for your first pilot. Suggested approach for Kerala specifically:

**Start with one doctor you trust** — ideally an ER consultant or senior resident at a private hospital in Thrissur, Kochi, or Kozhikode. Not a government hospital first — procurement and IT approvals will take months.

**Give them 2 weeks** with real patients. Ask them one question after each shift: *"Did the case sheet reflect what you said?"*

That feedback loop will tell you more than any further development session.

**The product is ready for that test.**
