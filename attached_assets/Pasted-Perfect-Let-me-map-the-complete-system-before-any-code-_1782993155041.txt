## Backend Routes Needed

```typescript
// 1. Cases filtered by role
GET /api/department/:id/cases
  ?date=2026-07-02
  &shift=evening
  &doctorId=xxx  (optional filter)

// Server logic:
if (role === 'resident') {
  return cases where doctorId === req.user.id
}
if (role === 'consultant') {
  return cases where shiftId === currentShift.id
  AND date === today
}
if (role === 'hod') {
  return ALL cases for department
  filtered by query params
}

// 2. Monthly rota
GET /api/department/:id/rota
  ?month=2026-07
  → returns all assignments for that month

POST /api/department/:id/rota/assign
  { shiftId, userId, date }
  → HOD assigns a doctor

POST /api/department/:id/rota/claim  
  { shiftId, date }
  → Doctor self-assigns

DELETE /api/department/:id/rota/:assignmentId
  → Remove assignment

// 3. HOD dashboard cases
GET /api/department/:id/all-cases
  ?startDate=2026-07-01
  &endDate=2026-07-31
  → Full month, all doctors, all shifts
  → Returns: date, time, doctorName,
             patientAge, complaint, 
             priority, status, shiftName
```
