## Updated GPT-4o Paediatric Rules

Add these to the system prompt:

```
PAEDIATRIC SPECIFIC RULES:

1. If age <= 16 → use paediatric framework
   Set isPatient: "paediatric"
   
2. Weight REQUIRED for paediatrics
   Extract: "12kg child", "weighs 20kg"
   If not mentioned → mark as missing
   
3. Drug doses are weight-based in paeds
   "paracetamol 15mg/kg" → 
   dose: "15mg/kg"
   calculatedDose: auto from weight
   
4. HEENT findings → examination.heent
   "throat red", "ear discharge",
   "fontanelle sunken" → heent field
   
5. Lactate normal range in paeds:
   0.5-2.0 mmol/L (same as adult)
   
6. ABG/VBG values — extract all:
   pH, pCO2, pO2, HCO3, BE, Lactate,
   SaO2, FiO2, Na, K, Cl, AG,
   Glucose, Hb, A-a Gradient
   
7. Anion Gap = Na - (Cl + HCO3)
   Normal 8-12
   >12 = high AG metabolic acidosis
   
8. Condition at time of shift:
   "stable for transfer" → Stable
   "unstable" / P1 / critical → Unstable
   
9. Fontanelle:
   "bulging fontanelle" → flag raised ICP
   "sunken fontanelle" → flag dehydration
   
10. Paediatric normal ranges differ:
    HR: varies by age
      Infant <1yr: 100-160
      Toddler 1-3yr: 90-150
      Preschool 3-6yr: 80-140
      School 6-12yr: 70-120
      Teen 12-18yr: 60-100
    RR also age-dependent
    BP lower than adults
    Flag if outside age-appropriate range
```
