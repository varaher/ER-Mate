## The Chat Behaviour for Type 2 User

```
The key difference from current chat:

CURRENT:
  Doctor pastes everything at once
  ErMate structures it all
  One shot

NEEDED FOR TYPE 2:
  Doctor pastes ONE PATIENT at a time
  ErMate adds each to a GROWING LIST
  Doctor sees the list building
  Doctor confirms each card
  Can edit any card before generating

This is the "build the list" mode
vs the "structure this dump" mode

ErMate needs to know which mode:
  Is the doctor adding to an existing list?
  Or is this a fresh dump?

Simple detection:
  If previous messages exist in this
  handover → "add to list" mode
  If first message → ask or auto-detect
```

## Tell Your Developer — Exact Spec

```
TWO HANDOVER MODES:

MODE 1 — "From my ErMate cases"
  Only available to logged-in users
  who have cases in the system

  HandoverChatScreen receives:
    mode: "from_cases"
    
  Shows case picker first
  Doctor selects patients
  Taps Generate
  Handover sheet built from
  existing case data in DB
  No AI extraction needed

MODE 2 — "Build from scratch"
  Available to anyone (no login needed
  for basic use)

  HandoverChatScreen receives:
    mode: "build_list"
    
  Starts with empty patient list
  Doctor adds patients one by one
  Each message = one patient
  ErMate extracts and adds to list
  Doctor sees growing card list
  After each patient ErMate asks:
    "Next patient? Or done?"
  
  When done → generate sheet
  
  If logged in → save to handover list
  If not logged in → share only
    (prompt to save: "Create free
     account to save this handover")

HANDOVER LIST SCREEN:
  Shows both types in the same list
  Badge shows source:
    🟢 ErMate cases
    📋 Pasted
    🎙️ Dictated

ACCUMULATOR STATE:
  The HandoverChatScreen needs to
  maintain a patients[] array
  that grows with each paste/dictation

  Each time doctor adds a patient:
    1. Extract patient data from message
    2. Add to patients[] array
    3. Show updated card list
    4. Ask for next patient

  patients[] is the source of truth
  for the final handover sheet
```
