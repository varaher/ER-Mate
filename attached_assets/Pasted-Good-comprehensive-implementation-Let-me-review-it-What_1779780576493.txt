## Concerns ⚠️

### 1. PAT Triangle Extraction Accuracy

The PAT (Pediatric Assessment Triangle) uses specific clinical terms:
- Appearance: tone, interactivity, consolability, look/gaze, speech/cry
- Work of Breathing: retractions, grunting, nasal flaring, head bobbing
- Circulation to Skin: pallor, mottling, cyanosis

When a doctor says naturally in Malayalam/English:
```
"കുട്ടി കരയുന്നുണ്ട്, active ആണ്, 
 consolable, mild retractions present"
```

The AI needs to map "കരയുന്നുണ്ട്" (crying) → tone normal, interactive. Verify the extraction prompt specifically lists PAT terminology so the AI knows what to look for.

### 2. Age Input Validation for Triage

The triage threshold function receives `patientAge` as a string from the patient form. If the doctor enters "4" for a 4-year-old, the comparison works. But if they enter "4 years" or "4y" the `parseInt` will still return 4. Confirm the age parsing is robust:

```javascript
// Verify this handles edge cases
const ageYears = parseInt(patientAge) || 0;
// "4" → 4 ✅
// "4y" → 4 ✅  
// "4 years" → 4 ✅
// "4.5" → 4 ✅ (months edge case)
// "18m" → 18 ❌ (would be 18 years not months)
```

For infants under 1 year, doctors often say "8 months" or "8m". Add a months handler:

```javascript
const parseAgeToYears = (ageStr) => {
  if (!ageStr) return 0;
  const str = String(ageStr).toLowerCase().trim();
  
  // Months format: "8m", "8 months", "8mo"
  if (str.includes('m') && 
      !str.includes('yr') && 
      !str.includes('year')) {
    return parseInt(str) / 12;
  }
  return parseInt(str) || 0;
};
```

### 3. Completeness Score Not Updated for Pediatric Fields

The `computeCompleteness` function checks 17 fields — all adult-oriented. For pediatric cases the score should additionally check:

```javascript
// Add to computeCompleteness when pediatric:
...(caseType === 'pediatric' ? [
  { label: "Weight", 
    filled: !!(ex?.patientWeight) },
  { label: "Immunization History", 
    filled: !!(ex?.immunizationHistory) },
  { label: "PAT Assessment", 
    filled: !!(ex?.patAssessment?.appearance) },
] : [])
```

Otherwise a pediatric case with weight, immunization, PAT all captured will still show 13/17 instead of reflecting those additional fields.

### 4. Birth History Edge Case

Birth history for Indian ER context often includes:
- Term/preterm
- Birth weight
- NICU admission
- Delivery type (normal/LSCS)

The extraction prompt should explicitly list these sub-fields or the AI will return a vague string like "normal delivery" without the structured data needed.
