## One Thing to Verify on Device

The new endpoint does create → PUT in sequence. But verify the external backend accepts a PUT immediately after a POST on the same case. Some backends have a slight propagation delay — the case ID exists but the record isn't fully indexed yet when the PUT arrives.

If you see cases created but clinical data missing, add a small guard:

```javascript
// After create, before PUT
// Give backend 500ms to settle
await new Promise(resolve => 
  setTimeout(resolve, 500)
);

// Then PUT clinical data
const updateResponse = await fetch(...)
```

Only add this if the problem appears. Don't add it preemptively.
