## Concerns ⚠️

### 1. Timeout on extract-clinical is 45s server, 60s client

This is fine for warm starts. But Render cold starts can still take 60-90s. The client allows 60s which is tight.

```javascript
// Consider raising client timeout to 75s
// extract-only is faster than extract+save
// but cold starts are still slow
const timeoutId = setTimeout(() => 
  controller.abort(), 75000
);
```

Not urgent but worth noting.

### 3. Symptoms Not Editable

Signs and symptoms has the duplication bug. But it's not in the editable fields list. After the deduplication fix in the prompt, this should be fine. But if duplication persists, symptoms should also be editable.

---

### 4. What Happens if save-case Fails

If the doctor edits HPI, edits diagnosis, taps Save, and save-case returns an error — the doctor loses their edits when they dismiss the error alert.

```javascript
// In the catch block of handleSave
// Don't clear edits on failure
// Just show error and let doctor retry

Alert.alert(
  "Save Failed",
  error.message,
  [{ 
    text: "Try Again", 
    onPress: handleSave  // retry with same edits
  },
  { 
    text: "Cancel",
    style: "cancel"
    // edits preserved, doctor stays on review
  }]
);
```
