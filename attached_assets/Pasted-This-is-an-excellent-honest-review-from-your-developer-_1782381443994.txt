## The Most Important Decision — Day 0

Before any code, your developer needs to lock this:

```
External backend (er-emr-backend.onrender.com)
  → Owns all clinical data
  → Cases, vitals, history, treatment
  → We CANNOT add columns here
  → We can only read case_id from it

Our local DB (PostgreSQL via Drizzle)
  → Owns all team/shift data
  → Stores case_id as a TEXT reference
  → No real foreign key to cases
  → Merges with external data on the client
```

**The merge pattern — tell your developer:**

```typescript
// Every case card in team mode = 
// external case data + our local overlay

async function getEnrichedCases(userId, shiftId) {
  // 1. Fetch cases from external backend
  const externalCases = await fetch(
    'https://er-emr-backend.onrender.com/api/cases',
    { headers: { Authorization: token } }
  );

  // 2. Fetch local shift/handover data
  const localOverlays = await db
    .select()
    .from(caseOverlays)
    .where(eq(caseOverlays.shiftId, shiftId));

  // 3. Merge on case_id
  return externalCases.map(c => ({
    ...c,
    overlay: localOverlays.find(o => o.caseId === c.id) || null
  }));
}
```
