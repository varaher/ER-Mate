## One Small Observation

The vitals defaults (80/120/80/98) are silently used when fields are left blank. This means a case created through Quick Case Sheet with no vitals entered will show HR 80, BP 120/80, SpO2 98 on the Patient tab — which looks like real data.

A doctor reviewing the case later won't know if those are actual vitals or defaults.

```javascript
// Instead of silent defaults
// leave vitals blank if not entered
// so the Patient tab shows empty fields
// that the doctor consciously fills

const hrValue = hrRef.current?.value || '';
// not || '80'

// Empty fields on Patient tab are honest
// Pre-filled defaults are misleading
```

Tell your developer — if Quick Case Sheet vitals are left blank, pass empty strings to the case sheet, not default values. Empty fields prompt the doctor to fill them. Silent defaults create false records.
