## Issue 1 — Phone Lock Stops Recording

This is a known iOS/Android background audio problem. When the screen locks, the browser tab is backgrounded and MediaRecorder pauses or stops.

**Tell your developer:**

```javascript
// In VoiceCaseSheetScreen
// Add wake lock to prevent screen sleeping
// during recording

const startRecording = async () => {
  // Request wake lock
  let wakeLock = null;
  
  try {
    if ('wakeLock' in navigator) {
      wakeLock = await navigator
        .wakeLock.request('screen');
    }
  } catch (err) {
    // Wake lock not supported — continue anyway
    console.log('Wake lock not available');
  }
  
  // Store so we can release later
  wakeLockRef.current = wakeLock;
  
  // Start recording as normal...
};

const stopRecording = async () => {
  // Release wake lock when done
  if (wakeLockRef.current) {
    await wakeLockRef.current.release();
    wakeLockRef.current = null;
  }
  // Stop recording as normal...
};
```

Also add a visible indicator while recording so the doctor knows it's active:

```
🔴 Recording... 00:42
    Keep screen on while recording
```
