## One Thing Worth Verifying

Since the doctor is recording a **natural conversation** — not a structured dictation — the transcript will contain things that should NOT go into the case sheet:

```
Doctor: "ஒரு நாள் முன்னாடி இருந்து 
         face twist ஆகுதா?"
         (Has the face been twisted 
         since one day before?)

Patient: "ஆமா doctor, நேத்து evening 
          இருந்து"
          (Yes doctor, since yesterday 
          evening)

Bystander: "சாப்பிட மறுக்குறாரு"
            (He's refusing to eat)

Doctor: "BP எடு"
         (Take BP)
Nurse: "150/90 sir"
```

The AI extraction prompt must be smart enough to:

```javascript
// Extract clinically relevant content only
// IGNORE conversational filler like:
// - "okay", "hmm", "let me check"
// - Nurse instructions mid-recording
// - Repeated questions for clarification
// - Background noise transcribed as text

// The master prompt already handles this with:
"Extract ALL clinical information.
Ignore conversational filler, 
repeated confirmations, and 
non-clinical dialogue."
```

Verify this instruction is explicitly in your current master extraction prompt. If it's not, add it. Without it, the HPI narrative field will contain the full back-and-forth conversation rather than a clean clinical summary.
