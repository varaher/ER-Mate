## How It Works for ErMate

```
Doctor opens ermate.in on desktop
         ↓
Shows QR code (unique session token)
         ↓
Doctor scans with ErMate mobile app
         ↓
Desktop browser gets same session
         ↓
Full ErMate accessible on desktop
Same case, same data, real-time sync
```

## Technical Implementation

### Step 1 — Generate QR on Desktop

```javascript
// Backend generates a linking token
const generateLinkToken = async (userId) => {
  const token = crypto.randomUUID();
  
  // Store in Redis/DB with 5 min expiry
  await redis.setex(
    `device_link:${token}`, 
    300, // 5 minutes
    JSON.stringify({ 
      userId, 
      status: 'pending',
      createdAt: Date.now()
    })
  );
  
  return token;
};

// Desktop shows QR containing
// "https://ermate.in/link?token=xxxx"
```

### Step 2 — Mobile Scans and Approves

```javascript
// When doctor scans QR in ErMate mobile app
const approveLinking = async (token) => {
  const authToken = await getAuthToken();
  
  await fetch('/api/device-link/approve', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${authToken}`
    },
    body: JSON.stringify({ token })
  });
};
```

### Step 3 — Desktop Polls for Approval

```javascript
// Desktop polls every 2 seconds
const pollForApproval = async (linkToken) => {
  const interval = setInterval(async () => {
    const res = await fetch(
      `/api/device-link/status?token=${linkToken}`
    );
    const data = await res.json();
    
    if (data.status === 'approved') {
      clearInterval(interval);
      // Store session token for desktop
      localStorage.setItem('auth_token', data.authToken);
      // Redirect to dashboard
      window.location.href = '/dashboard';
    }
    
    if (data.status === 'expired') {
      clearInterval(interval);
      // Regenerate QR
      refreshQRCode();
    }
  }, 2000);
};
```

## One Important Difference from WhatsApp Web

WhatsApp Web keeps your phone as the server — disconnect phone, lose desktop access. **Don't do this for ErMate.**

ErMate desktop should connect directly to your backend — phone just approves the session once. After that, desktop is fully independent. Doctor can close the mobile app and desktop keeps working.

```
WhatsApp model:  Desktop → Phone → Server
ErMate model:    Desktop → Server ← Phone
                 (phone only needed for QR scan)
```

This is better for clinical use — a doctor shouldn't lose desktop access mid-shift because their phone battery died.
