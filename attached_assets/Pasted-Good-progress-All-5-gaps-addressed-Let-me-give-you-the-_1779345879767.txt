## What Needs Verification ⚠️

### Gap 3 — Completeness Score
16 fields is better than 10. But I notice VBG is checked as "VBG/Labs ordered" — meaning it passes as complete if *any* lab is ordered, even if the VBG values themselves are empty.

**This needs to be two separate checks:**
```javascript
// Current — too loose
'investigations.labsOrdered' // passes if any lab mentioned

// Should be
'investigations.labsOrdered',  // labs check
'investigations.vbg.ph',       // VBG check — only if 
                                // VBG was mentioned
```

The VBG check should be **conditional** — only required if the doctor mentioned a VBG in their dictation. Otherwise a simple chest pain case without VBG will always show as incomplete.

```javascript
// Conditional required fields
const getRequiredFields = (caseData) => {
  const base = [
    'patient.name',
    'patient.age',
    'chiefComplaint.complaint',
    // ... core fields always required
  ];
  
  // Only require VBG if it was mentioned
  const mentionedVBG = 
    caseData.investigations?.vbg?.ph !== "";
  if (mentionedVBG) {
    base.push('investigations.vbg.lactate');
    base.push('investigations.vbg.hco3');
  }
  
  // Only require consultation fields 
  // if a consultation was mentioned
  const hasConsult = 
    caseData.doctors?.consultations?.length > 0;
  if (hasConsult) {
    base.push('doctors.consultations[0].adviceGiven');
  }
  
  return base;
};
```

## One New Issue Spotted 🔴

The implementation mentions:

*"VBG appears in the Investigations section and consultations appear under Procedures in the generated course narrative"*

**Consultations should NOT appear under Procedures.** In Indian ER documentation, procedures are interventions — intubation, central line, chest tube. Consultations are a separate section.

The discharge summary structure should be:

```
1. Presenting Complaint
2. History
3. Examination
4. Investigations          ← VBG here
5. Course in Hospital
6. Consultations           ← separate section, not under procedures
7. Procedures              ← only actual interventions
8. Diagnosis
9. Discharge Advice
```

This is a one-line fix in the discharge prompt — move consultations out of the procedures block into their own section.
