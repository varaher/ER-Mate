## The Two Problems Identified

### Problem 1 — Review Screen Not Appearing

**Extract-clinical returned 200 with data at 11:17:27.** That's confirmed working. But the Review screen didn't open.

The issue is in the client. The response shape is:
```javascript
{"success":true,"extracted":{...}}
```

But the client code is likely reading:
```javascript
const extracted = data.extracted || data;
```

Check if `data.extracted` is actually being set correctly after the response. The log confirms the server returned it — so this is a frontend state issue.

### Problem 2 — Dashboard Cases Not Showing

```
[PROXY] No user field found on cases
```

This log appears repeatedly. The proxy is fetching cases from the external backend but the cases have no `user` field — so the proxy filter is removing them all.

This was working before. The rewrite of `save-case` likely changed how cases are created — they're being saved without the user ID attached, so the proxy can't match them to the logged-in doctor.
