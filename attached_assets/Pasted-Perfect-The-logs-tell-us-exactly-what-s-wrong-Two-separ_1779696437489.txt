## Issue 1 — Case Creation Failing (422 Error)

```
"Field required: body.patient.phone"
```

The external backend **requires a phone number field** but ErMate is not sending it. The case creation fails with 422 before any clinical data is saved.

**Fix — add phone field to the create payload:**

```javascript
// In the extract-and-save endpoint
// Find the case creation POST body
// Add these missing required fields:

body: JSON.stringify({
  patient: {
    name: patientName || 'Unknown',
    age: patientAge || '',
    sex: patientGender || 'Male',
    phone: patientPhone || '',  // ← ADD THIS
    mode_of_arrival: modeOfArrival || 'Walk-in',
    address: 'Not provided',
    brought_by: 'Self',
    informant_name: patientName || 'Unknown',
    informant_reliability: 'Reliable',
    identification_mark: 'None noted',
    arrival_datetime: new Date().toISOString()
  }
})
```

Also the log shows `name: "H"` — the patient name is only getting the first letter. The patientInfo.name is being truncated. Fix:

```javascript
// Verify full name is passed
// not just first character
patientName: patientInfo?.name || 
             patientInfo?.patientName || 
             'Unknown'
```

## Issue 2 — Sarvam 30 Second Limit

```
"Audio duration exceeds the maximum 
limit of 30 seconds"
```

Also ffmpeg is not installed so the audio conversion is failing before Sarvam even sees it properly.

```
[AudioConvert] ffmpeg conversion failed: 
spawn ffmpeg ENOENT
```

**Fix — skip ffmpeg conversion, send audio directly:**

```javascript
// In sarvamAI.ts transcription function
// Don't try to convert with ffmpeg
// Send the webm directly to Whisper
// for recordings over 30 seconds

const fileSizeKB = audioBuffer.length / 1024;
const estimatedSeconds = fileSizeKB / 32;

if (estimatedSeconds > 25) {
  // Skip Sarvam — go straight to Whisper
  console.log('[STT] Long recording detected,' +
    'using Whisper directly');
  return await transcribeWithWhisper(audioBuffer);
}

// Under 25 seconds — use Sarvam
return await transcribeWithSarvam(audioBuffer);
```
