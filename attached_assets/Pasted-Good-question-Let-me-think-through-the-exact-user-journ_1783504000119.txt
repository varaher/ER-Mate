## The Real Problem

```
Doctor wants to hand over at shift end.
Their hospital EMR has all the notes.

How does the data GET into ErMate?

Option A — Copy paste
  Doctor selects all text in EMR
  Copies it
  Opens ErMate
  Pastes it
  
  REALITY: Hospital EMRs are often
  locked browsers, thin clients,
  or desktop software. Copy-paste
  may not even work on all systems.
  Selecting 12 hours of notes is messy.

Option B — Screenshot
  Doctor screenshots the EMR
  ErMate reads the image (OCR + AI)
  
  MUCH EASIER for the doctor.
  Phone camera → done.

Option C — Type or speak
  Doctor just describes patients
  to ErMate in the chat
  No EMR involvement at all
  
  This is what the handover chat
  already does.

Option D — API integration
  ErMate connects directly to the
  hospital EMR via HL7/FHIR
  Data flows automatically
  
  Long-term goal.
  Requires hospital IT buy-in.
  Not V1.
```

## What "Segregate" Means — How ErMate Splits the Data

```
When given messy EMR data (paste or photo)
ErMate separates it into buckets:

INPUT (messy, mixed):
  "08-07 11:32 Anjana: patient stable
   room waiting. 09:15 Dr Jamshid:
   handover from Dr Surya, BP 150/80,
   admitted under Salini. 08:15 Anjana:
   BP 160/90 informed doctor BP meds given.
   09:30 consultation done MgSO4 advised..."

OUTPUT BUCKETS:

BUCKET 1 — PATIENT IDENTITY
  Name: [not found → ask]
  Age/Sex: [not found → ask]
  Bed: [not found → ask]
  Admitting: Dr. Salini (Gen Medicine)

BUCKET 2 — CURRENT VITALS
  BP: 150/80 (was 160/90 at 08:15)
  HR: 76
  SpO2: 98% room air

BUCKET 3 — CLINICAL EVENTS
  08:15 → BP spike 160/90 → treated
  09:30 → Gen Med review → MgSO4 started

BUCKET 4 — PENDING TASKS
  □ Blood results (sent 07:55 — pending)
  □ Room allocation (overnight wait)
  □ MgSO4 monitoring
  □ BP recheck

BUCKET 5 — CURRENT MEDICATIONS
  MgSO4 infusion (started 09:40)
  BP medications (name not specified)
  MAR medications (names not specified)

BUCKET 6 — STATUS
  Vitally stable
  Room waiting — overnight

BUCKET 7 — HANDOVER TRAIL
  Night: Dr. Surya → Dr. Theja
  Nursing: RN Tincy → RN Abila → RN Anjana
```

**Feature 2 — Smart paste cleanup**

```typescript
// In HandoverChatScreen.tsx
// When doctor pastes text:

const handlePaste = async (rawText) => {
  // Show "Reading your notes..." 
  setStatus('processing');
  
  const response = await fetch('/api/handover/structure', {
    method: 'POST',
    body: JSON.stringify({ rawText })
  });
  
  const { patients, questions } = response;
  
  // Show patient cards
  addMessage({ type: 'patientCards', patients });
  
  // Ask about gaps
  if (questions.length > 0) {
    addMessage({
      type: 'questions',
      text: `Before I generate the handover, 
             a few quick things:\n${questions.join('\n')}`
    });
  }
};
```

## The Segregation Logic — What ErMate Must Identify

```
From ANY input (photo, paste, or speech)
ErMate must find and separate:

WHO → Patient identity
  Name, Age, Sex, Bed number, ER number

WHAT → Clinical status
  Primary diagnosis
  Current condition (stable/unstable)

HOW → Vitals
  Latest BP, HR, SpO2, Temp, RR, GCS
  Any changes in the last shift

WHAT HAPPENED → Events
  Any clinical deterioration
  Any new diagnosis
  Any procedure done
  Any consultation done
  Any medication started/changed

WHAT'S RUNNING → Current medications
  IV infusions with rates
  Regular medications
  PRN medications

WHAT'S LEFT → Pending tasks
  Tests ordered but not resulted
  Reviews requested but not done
  Medications due at specific times
  Follow-ups needed

WHO'S RESPONSIBLE → Staff
  Admitting consultant
  ER doctor
  Nursing team

WHAT'S MISSING → Gaps
  Anything ErMate couldn't find
  → Ask the doctor
```
