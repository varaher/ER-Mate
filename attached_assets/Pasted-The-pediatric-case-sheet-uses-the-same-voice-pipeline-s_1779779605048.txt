## What's Different for Pediatrics ⚠️

**1. Age-adjusted vitals**
A HR of 140 in an adult = ORANGE triage. In a 2-year-old = completely normal. The triage auto-assign uses adult thresholds. For pediatric cases it needs age-adjusted values.

**2. Pediatric-specific history fields**
The extraction prompt doesn't currently ask for:
```
Immunization history
Birth history (term/preterm, NICU)
Feeding history
Developmental milestones
Weight in kg (for drug dosing)
```

**3. Weight-based medication dosing**
When the doctor says "Paracetamol 15mg/kg" — the extraction needs to capture weight and calculate the dose. Currently it just captures the dose as stated.

**4. PALS vs ATLS framework**
Pediatric primary survey follows PALS parameters, not ATLS. The extraction prompt uses ATLS language.

## What to Tell Your Developer

**Three pediatric-specific fixes needed:**

**Fix 1 — Pediatric triage thresholds**
```javascript
// Current computeTriageFromVitals uses 
// adult thresholds only

// Add age-based adjustment:
const getPediatricThresholds = (ageYears) => {
  if (ageYears < 1) return {
    hrHigh: 160, rrHigh: 60, 
    spo2Low: 94, bpLow: 60
  };
  if (ageYears < 5) return {
    hrHigh: 140, rrHigh: 40,
    spo2Low: 94, bpLow: 70
  };
  if (ageYears < 12) return {
    hrHigh: 120, rrHigh: 30,
    spo2Low: 95, bpLow: 80
  };
  // 12-16 — close to adult
  return {
    hrHigh: 100, rrHigh: 20,
    spo2Low: 95, bpLow: 90
  };
};
```
