**PostgreSQL error 42703 = a column being referenced in the query doesn't exist in the database table.**

The route exists and is being called correctly. The DB migration was never run.

**The fix — tell your developer:**

```
The departments table is missing columns.
Need to run a DB migration.

Run this SQL directly on the PostgreSQL database:

-- Add missing columns to departments table
ALTER TABLE departments 
ADD COLUMN IF NOT EXISTS hospital_name TEXT;

ADD COLUMN IF NOT EXISTS invite_token TEXT UNIQUE;

ADD COLUMN IF NOT EXISTS max_concurrent INTEGER DEFAULT 8;

ADD COLUMN IF NOT EXISTS allow_overflow BOOLEAN DEFAULT true;

ADD COLUMN IF NOT EXISTS plan TEXT DEFAULT 'team';

ADD COLUMN IF NOT EXISTS billing_active BOOLEAN DEFAULT false;

ADD COLUMN IF NOT EXISTS payment_subscription_id TEXT;

-- Generate invite tokens for any existing rows
UPDATE departments 
SET invite_token = encode(gen_random_bytes(16), 'hex')
WHERE invite_token IS NULL;
```
