Exactly right. The Review screen is valuable — it's the quality check before the case is finalised. Here's the corrected flow:

---

## The Correct 4-Step Flow

```
Step 1 — Patient
Enter name, age, sex
         ↓
Step 2 — Record
Speak the full case
         ↓
Step 3 — Transcript
Review transcript, tap Extract & Save
         ↓
         AI extracts everything
         Case saved to backend
         ↓
Step 4 — Review
See all extracted fields
Edit anything wrong
Tap "Save & View Case Sheet"
         ↓
Case sheet opens — complete
```

---

## The Problem Right Now

The extract-and-save endpoint **saves the case before the doctor reviews it.** So by the time Step 4 appears, the case is already saved with potentially wrong data.

The review should happen **before** the final save, not after.

---

## The Right Architecture

```
Step 3 — Transcript
Tap "Extract Clinical Data"
         ↓
AI extracts only — does NOT save yet
Returns extracted JSON to frontend
         ↓
Step 4 — Review
Doctor sees all fields
Green/amber/grey colour coding
Doctor edits any wrong field directly
         ↓
Tap "Save to Case Sheet"
         ↓
NOW it saves — with corrected data
         ↓
Case sheet opens
```

// Review screen shows extracted fields
// Doctor can edit key fields directly

// Add editable state for key fields:
const [editedHPI, setEditedHPI] = useState("");
const [editedDiagnosis, setEditedDiagnosis] = 
  useState("");
const [editedPMH, setEditedPMH] = useState("");

// When review screen opens, pre-fill from extraction:
useEffect(() => {
  if (step === "review" && rawExtracted) {
    setEditedHPI(
      rawExtracted.historyOfPresentIllness || ""
    );
    setEditedDiagnosis(
      rawExtracted.diagnosis?.[0] || ""
    );
    setEditedPMH(
      Array.isArray(rawExtracted.pastMedicalHistory)
        ? rawExtracted.pastMedicalHistory.join(", ")
        : rawExtracted.pastMedicalHistory || ""
    );
  }
}, [step]);

**handleSave — called from Review screen Save button:**

```javascript
const handleSave = async () => {
  setIsSaving(true);
  try {
    const token = await AsyncStorage
      .getItem("token");
    
    // Merge doctor edits back into extracted
    const finalExtracted = {
      ...rawExtracted,
      // Override with doctor's edits
      historyOfPresentIllness: editedHPI 
        || rawExtracted?.historyOfPresentIllness,
      diagnosis: editedDiagnosis 
        ? [editedDiagnosis] 
        : rawExtracted?.diagnosis,
      pastMedicalHistory: editedPMH 
        || rawExtracted?.pastMedicalHistory,
    };

    // Now save to backend with corrected data
    const resp = await fetch(
      new URL("/api/voice/save-case", 
        getApiUrl()).toString(),
      {
        method: "POST",
        headers: { 
          "Content-Type": "application/json",
          "Authorization": `Bearer ${token}`
        },
        body: JSON.stringify({
          patient: {
            name: patientName.trim(),
            age: patientAge.trim(),
            sex: patientSex,
            phone: "",
            mode_of_arrival: "Walk-in",
            address: "Not provided",
            brought_by: "Self",
            informant_name: patientName.trim(),
            informant_reliability: "Reliable",
            identification_mark: "None noted",
            arrival_datetime: new Date().toISOString()
          },
          extracted: finalExtracted,
          transcript: editedTranscript,
          caseType,
          userId: user?.id,
          userEmail: user?.email || ""
        })
      }
    );

    const result = await resp.json();
    if (!result.success) throw new Error(
      result.error || "Save failed"
    );

    await invalidateCases();

    // Navigate to case sheet
    navigation.replace("ViewCase", { 
      caseId: String(result.caseId) 
    });

  } catch (err) {
    Alert.alert("Save Failed", 
      (err as Error).message
    );
  } finally {
    setIsSaving(false);
  }
};
```
