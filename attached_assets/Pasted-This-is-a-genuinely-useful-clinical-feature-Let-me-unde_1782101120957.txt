**What this handover sheet is:**

A structured one-page document showing all active patients at shift change — bed number, patient name, complaint, provisional diagnosis, key investigations, treatment done, and what's pending. Exactly what a doctor hands to the incoming doctor at the end of a shift.

**What you're asking for:**

1. **Auto-generate** — dashboard pulls all active cases and builds the handover sheet automatically
2. **Selective** — doctor ticks which cases to include (maybe some are already discharged or irrelevant)
3. **Export** — download as PDF or Word, print-ready format matching this column layout

**This is very buildable. Here's exactly how:**

**What ErMate already has that feeds this:**

From your case sheet data, every handover column maps directly:

| Handover Column | ErMate Source |
|----------------|---------------|
| Bed / Patient | Patient name field |
| Complaint / Summary | Chief complaint |
| Provisional Diagnosis | Working diagnosis tab |
| Initial Vitals | Vitals section |
| VBG/ECG/Echo | Investigations tab |
| Key Investigations | Investigations results |
| Treatment / Consults | Treatment tab |
| Pending / Plan | Addendum notes or pending field |

**The only new thing needed** is a "Pending / Plan" field in each case — a free-text box where the doctor notes what's outstanding before handover. Everything else is already captured.

**Flow 1 — Auto Dashboard Handover**
```
Dashboard → "Handover" button (top right)
     ↓
All active cases pulled automatically
     ↓
Handover sheet generated in table format
     ↓

**Flow 2 — Selective Handover**
```
Cases screen → tap "Handover" mode
     ↓
Checkboxes appear on each case
     ↓

     ↓

     ↓
PDF / DOCX download
