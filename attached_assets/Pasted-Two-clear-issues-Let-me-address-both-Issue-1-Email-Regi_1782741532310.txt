## Issue 1 — Email Registration and Login Broken

**Root cause — same Resend problem:**

```
Registration:
  Form submits → user created in DB
  Welcome email fires → Resend fails
  Whole request crashes
  Doctor sees "failed" but account exists

Login with email:
  Doctor tries to log in with email they 
  registered — gets error
  Because registration appeared to fail,
  they don't know the account exists
```

**Tell your developer — two fixes:**

**Fix A — Wrap email in try/catch (5 minutes)**
```typescript
// server/routes/auth.ts — register route

// BEFORE:
await sendWelcomeEmail(user.email, user.name);

// AFTER:
try {
  await sendWelcomeEmail(user.email, user.name);
} catch (err) {
  console.error('[Email] Welcome email failed:', err.message);
  // Never block registration for email failure
}

// Registration succeeds regardless
res.json({ success: true, token, user });
```

**Fix B — Same for forgot password route**
```typescript
// server/routes/auth.ts — forgot password route

try {
  await sendPasswordResetEmail(email, resetLink);
} catch (err) {
  console.error('[Email] Reset email failed:', err.message);
}

// Still return success so user isn't confused
res.json({ 
  message: "If this email exists, a reset link was sent." 
});
```

## How It Works Technically

**Tell your developer:**

```typescript
// New route: POST /api/auth/set-password
// Auth required (must be logged in)

app.post('/api/auth/set-password', 
  requireAuth, 
  async (req, res) => {
    const { password, confirmPassword } = req.body;
    
    if (password !== confirmPassword) {
      return res.status(400).json({ 
        error: 'Passwords do not match' 
      });
    }
    
    if (password.length < 8) {
      return res.status(400).json({ 
        error: 'Password must be at least 8 characters' 
      });
    }
    
    // Hash and save
    const hashed = await bcrypt.hash(password, 10);
    
    await db.update(users)
      .set({ 
        passwordHash: hashed,
        hasPassword: true  // new column
      })
      .where(eq(users.id, req.user.id));
    
    res.json({ success: true });
  }
);

// Also update: POST /api/auth/change-password
// For users who already have a password

app.post('/api/auth/change-password',
  requireAuth,
  async (req, res) => {
    const { currentPassword, newPassword } = req.body;
    
    // Verify current password first
    const user = await db.select()
      .from(users)
      .where(eq(users.id, req.user.id))
      .limit(1);
    
    const valid = await bcrypt.compare(
      currentPassword, 
      user[0].passwordHash
    );
    
    if (!valid) {
      return res.status(401).json({ 
        error: 'Current password is incorrect' 
      });
    }
    
    const hashed = await bcrypt.hash(newPassword, 10);
    await db.update(users)
      .set({ passwordHash: hashed })
      .where(eq(users.id, req.user.id));
    
    res.json({ success: true });
  }
);
```

**Schema — add one column:**
```sql
ALTER TABLE users 
ADD COLUMN IF NOT EXISTS has_password 
BOOLEAN DEFAULT false;
```
