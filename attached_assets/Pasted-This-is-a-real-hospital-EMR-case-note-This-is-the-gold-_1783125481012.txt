## Key Observations From the Real EMR

**1. GCS shown in components:**
```
Hospital shows: GCS: E4 V5 M6
Not just: GCS 15

ErMate should extract:
E + V + M components if spoken
"E4V5M6" or "GCS 14, E3V5M6"
Then display as: GCS: E4 V5 M6 (15/15)
```

**2. Temperature in Fahrenheit:**
```
Hospital shows: Temp: 98.6°F
ErMate shows: 36.8°C

Both should be supported
If doctor says "98.6" → Fahrenheit
If doctor says "36.8" → Celsius
Auto-convert and show both:
Temp: 98.6°F (36.8°C)
```

**3. LMP included for female patients:**
```
Hospital includes: LMP: 14/6/26

ErMate must:
If patient is female → always include LMP
Extract from dictation: "LMP 14th June"
If not mentioned → "LMP: Not mentioned"
Add to history section
```

**4. Differential diagnosis with reasoning:**
```
Hospital shows:
"Acute appendicitis (most likely given
 pain migration to RIF and tachycardia)"

ErMate differentials should include
the clinical reasoning in brackets
Not just the diagnosis name
```

**5. History of Present Illness is a narrative:**
```
Hospital shows a full paragraph:
"Patient presented with abdominal pain 
 since the previous evening at approximately
 5:30 PM. The pain was initially located 
 in the epigastric region and subsequently
 migrated to the right iliac fossa..."

NOT bullet points
A proper clinical narrative paragraph
GPT-4o should generate this from
all the history fields combined
```

**6. Psychological assessment as a sentence:**
```
Hospital: "No features of depression, 
anxiety, psychosis, agitation, suicidal 
ideation, or substance use."

When all psych toggles are off →
auto-generate this standard sentence
When any toggle is on →
"Patient has [feature]. [details]."
```
