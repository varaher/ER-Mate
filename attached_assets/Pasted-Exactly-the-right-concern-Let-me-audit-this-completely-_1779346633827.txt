## The Core Problem

Your developer is building the discharge summary prompt by **manually listing fields** to pass. Every time a new field is added to the case sheet, someone has to remember to also add it to the discharge route. That's how gaps happen.

**The fix is to pass the entire master schema object once — not field by field.**

## The Right Architecture

```javascript
// In the discharge route — pass everything
const generateDischargeSummary = async (caseId) => {
  const token = await getAuthToken();
  
  // Fetch the complete saved case
  const caseResponse = await fetch(
    `/api/cases/${caseId}`,
    { headers: { 'Authorization': `Bearer ${token}` }}
  );
  const fullCase = await caseResponse.json();

  // Pass the ENTIRE case object to the prompt
  // AI reads what it needs — nothing is forgotten
  const response = await fetch(
    '/api/ai/discharge-summary',
    {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${token}`
      },
      body: JSON.stringify({
        caseId,
        fullCase  // ← entire master schema, not cherry-picked fields
      })
    }
  );
};
```
