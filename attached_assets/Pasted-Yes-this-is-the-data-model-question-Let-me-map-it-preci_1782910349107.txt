## The Complete Mapping as Code

This is what your developer needs to build:

```typescript
// One source of truth — the case object
interface CaseData {
  // Patient
  name: string;
  age: number;
  gender: string;
  priority: "P1"|"P2"|"P3"|"P4"|"P5";
  vitals: {
    hr: string; bp: string; spo2: string;
    rr: string; temp: string; gcs: string; grbs: string;
  };

  // History (SAMPLE)
  history: {
    symptoms: string;
    allergies: string;
    medications: string;
    pastHistory: string;
    lastMeal: string;
    events: string;
    familyHistory: string;
    socialHistory: string;
  };

  // Primary Survey
  primary: {
    airway: string; breathing: string;
    circulation: string; disability: string;
    exposure: string; ecg: string; abg: string;
  };

  // Examination
  exam: {
    general: string; cvs: string; respiratory: string;
    abdomen: string; neuro: string; psych: string;
  };

  // Treatment
  treatment: {
    medications: string; procedures: string;
    ivAccess: string; fluids: string;
    oxygen: string; consults: string;
  };

  // Notes
  notes: { addendum: string; };

  // Disposition
  disposition: {
    diagnosis: string; differentials: string;
    plan: string;
    decision: "admit"|"discharge"|"transfer"|"deceased";
    referralSpecialty: string;
    followUp: string;
    instructions: string;
  };

  // Meta
  doctorName: string;
  department: string;
  date: string;
  caseNumber: string;
}

// ─────────────────────────────────────────────────
// DOCUMENT GENERATORS — all fed from same CaseData
// ─────────────────────────────────────────────────

function generateCaseNote(c: CaseData): string {
  return `
EMERGENCY CASE NOTE
Case #${c.caseNumber} · ${c.date}
Doctor: ${c.doctorName} · ${c.department}

PATIENT
${c.name}, ${c.age}${c.gender} · ${c.priority}

VITALS
HR: ${c.vitals.hr} · BP: ${c.vitals.bp}
SpO₂: ${c.vitals.spo2} · RR: ${c.vitals.rr}
Temp: ${c.vitals.temp} · GCS: ${c.vitals.gcs}
GRBS: ${c.vitals.grbs}

HISTORY (SAMPLE)
Symptoms:     ${c.history.symptoms}
Allergies:    ${c.history.allergies}
Medications:  ${c.history.medications}
Past History: ${c.history.pastHistory}
Last Meal:    ${c.history.lastMeal}
Events:       ${c.history.events}

PRIMARY SURVEY (ABCDE)
A: ${c.primary.airway}
B: ${c.primary.breathing}
C: ${c.primary.circulation}
D: ${c.primary.disability}
E: ${c.primary.exposure}
ECG: ${c.primary.ecg}

EXAMINATION
${c.exam.general}
CVS: ${c.exam.cvs}
Respiratory: ${c.exam.respiratory}
Abdomen: ${c.exam.abdomen}
Neurological: ${c.exam.neuro}

TREATMENT GIVEN
${c.treatment.medications}
Procedures: ${c.treatment.procedures}
IV Access: ${c.treatment.ivAccess}
Fluids: ${c.treatment.fluids}
Oxygen: ${c.treatment.oxygen}
Consults: ${c.treatment.consults}

CLINICAL NOTES
${c.notes.addendum}

IMPRESSION
${c.disposition.diagnosis}

DIFFERENTIALS
${c.disposition.differentials}

PLAN
${c.disposition.plan}
  `.trim();
}

function generateDischargeSummary(c: CaseData): string {
  return `
DISCHARGE SUMMARY
${c.name}, ${c.age}${c.gender}
Date: ${c.date} · ${c.department}
Doctor: ${c.doctorName}

PRESENTING COMPLAINT
${c.history.symptoms}
${c.history.events}

BACKGROUND
${c.history.pastHistory}
Home medications: ${c.history.medications}
Allergies: ${c.history.allergies}

DIAGNOSIS
${c.disposition.diagnosis}

INVESTIGATIONS DONE
ECG: ${c.primary.ecg}
ABG: ${c.primary.abg}

TREATMENT GIVEN
${c.treatment.medications}
${c.treatment.procedures}
Oxygen: ${c.treatment.oxygen}

DISPOSITION
Decision: ${c.disposition.decision}
${c.disposition.plan}

FOLLOW-UP
${c.disposition.followUp}

INSTRUCTIONS
${c.disposition.instructions}
  `.trim();
}

function generateReferralLetter(c: CaseData, toSpecialty: string): string {
  return `
REFERRAL LETTER
Date: ${c.date}
From: ${c.doctorName}, ${c.department}
To: Consultant ${toSpecialty}

Re: ${c.name}, ${c.age}${c.gender}
Allergies: ${c.history.allergies}

Dear Dr.,

We are referring the above patient presenting with:
${c.history.symptoms}

Background: ${c.history.pastHistory}

Vitals on arrival:
HR ${c.vitals.hr} · BP ${c.vitals.bp} · SpO₂ ${c.vitals.spo2}

Treatment given:
${c.treatment.medications}

Diagnosis: ${c.disposition.diagnosis}

${c.disposition.plan}

Kindly review and manage accordingly.

Dr. ${c.doctorName}
${c.department}
  `.trim();
}
```

## What This Means Practically

```
Doctor updates ANYTHING in any tab
         ↓
CaseData object updates
         ↓
All three documents regenerate automatically
         ↓
Doctor taps Copy on any document
         ↓
Gets the latest version with all updates

Example:
  Doctor adds penicillin allergy via chat
  → history.allergies = "Penicillin"
  → Case note regenerates with penicillin
  → Discharge summary regenerates with penicillin
  → Referral letter regenerates with penicillin
  → All three are in sync
  → Doctor copies any of them — always accurate
```

## The Key Principle — One Source, Many Outputs

```
CaseData object
      │
      ├── generateCaseNote()      → 📋 Case Note
      ├── generateDischargeSummary() → 📄 Discharge Summary
      ├── generateReferralLetter()   → 📨 Referral Letter
      └── generateTransferNote()     → 🚑 Transfer Note (future)

Change the data once.
All documents update.
Doctor never manually updates a document.
```

This is the core architecture — one data object, multiple document renderers all reading from it. Tell your developer: **CaseData is the single source of truth. No document stores its own data. All documents are generated on demand from CaseData.**
