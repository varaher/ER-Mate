## Tap a Card — Opens the Handover

```
Three states when opening:

STATE 1 — Completed handover (read only)
  Shows the full handover sheet
  All patient cards
  Timeline per patient
  [Share again] [Export PDF]

STATE 2 — Draft (not yet shared)
  Shows the handover chat
  Doctor can continue editing
  [Generate sheet] [Share]

STATE 3 — Incoming handover
  Doctor is the RECEIVER
  Shows what was handed to them
  [Mark as received] button
  [Add notes] option
```

## Database — What's Needed

```sql
-- handovers table
CREATE TABLE handovers (
  id           UUID PRIMARY KEY,
  department_id INTEGER,
  from_doctor_id TEXT,
  from_doctor_name TEXT,
  to_doctor_id TEXT,
  to_doctor_name TEXT,
  shift_from   TEXT,  -- "Evening"
  shift_to     TEXT,  -- "Night"
  date         DATE,
  created_at   TIMESTAMP,
  status       TEXT,  
  -- "draft" | "shared" | "received"
  patient_count INTEGER,
  critical_count INTEGER,
  chat_messages JSONB, -- the conversation
  final_sheet   JSONB  -- structured output
);
```

## Backend Routes Needed

```typescript
// Get all handovers for doctor
GET /api/handovers
  ?departmentId=xxx
  ?limit=20&offset=0
  Returns: list ordered by date desc

// Get one handover
GET /api/handovers/:id
  Returns: full handover with patients

// Create new handover
POST /api/handovers
  body: { departmentId, shiftFrom, shiftTo }
  Returns: { id } → navigate to chat

// Update handover
PUT /api/handovers/:id
  body: { status, finalSheet, chatMessages }

// Mark as received
POST /api/handovers/:id/receive
  body: { receivingDoctorId }
  Updates status → "received"
  Sends notification to sender
```
