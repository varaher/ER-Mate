## The Merge Pattern — Critical

Since cases live on the external backend, the shift dashboard needs a merge:

```typescript
async function getShiftCases(shiftId, userId, role) {
  // 1. Who is on this shift?
  const sessions = await db
    .select()
    .from(shiftSessions)
    .where(
      and(
        eq(shiftSessions.shiftId, shiftId),
        eq(shiftSessions.status, "active")
      )
    );

  // 2. What cases do they have? (from case_overlays)
  const overlays = await db
    .select()
    .from(caseOverlays)
    .where(eq(caseOverlays.shiftId, shiftId));

  // 3. Fetch those cases from external backend
  const caseIds = overlays.map(o => o.caseId);
  const externalCases = await fetchCasesFromExternal(caseIds);

  // 4. Merge
  const merged = externalCases.map(c => ({
    ...c,
    overlay: overlays.find(o => o.caseId === c.id),
    doctor: sessions.find(s => s.userId === c.createdByUserId),
  }));

  // 5. Filter by role
  if (role === "resident") {
    return merged.filter(c => c.createdByUserId === userId);
  }
  // consultant and HOD see all
  return merged;
}
```
